# Chemkin to OpenFOAM Mechanism Converter

An interactive Python tool for converting Chemkin-format chemical reaction mechanisms into OpenFOAM 8–13 compatible chemistry files.

This tool takes three standard Chemkin files as input:

- reaction mechanism file
- thermodynamic data file
- transport data file

It first converts the Chemkin mechanism into Cantera YAML format using Cantera's `ck2yaml`, then converts the Cantera mechanism into OpenFOAM chemistry files.

The generated OpenFOAM files include:

```text
chem.yaml
thermos
reactions
elements
transportProperties
```

The program also computes pure-species dynamic viscosity data using Cantera and fits Sutherland transport parameters for each species.

---

## Features

- Interactive command-line interface
- Chemkin three-file input support
- Automatic Chemkin-to-Cantera YAML conversion using `ck2yaml`
- Conversion from Cantera YAML to OpenFOAM 8–13 chemistry format
- Automatic generation of:
  - `chem.yaml`
  - `thermos`
  - `reactions`
  - `elements`
  - `transportProperties`
- Sutherland transport parameter fitting for each species:
  - `As`
  - `Ts`
- Support for common combustion reaction types:
  - Arrhenius reactions
  - three-body Arrhenius reactions
  - Troe falloff reactions
  - Lindemann falloff reactions
  - pressure-dependent Arrhenius / PLOG reactions
- Optional evaluation of PLOG reactions at a fixed pressure

## Requirements

The recommended way to install the required libraries is through Conda.

Required Python packages:

- Cantera
- NumPy
- SciPy

## Installation

Create the Conda environment:

```bash
conda env create -f environment.yml
```

Activate the environment:

```bash
conda activate chemkin2foam
```

Example `environment.yml`:

```yaml
name: chemkin2foam
channels:
  - conda-forge
dependencies:
  - python=3.11
  - cantera
  - numpy
  - scipy
```

## Usage

Run the program:

```bash
python chemkinToOpenFOAM.py
```

The program will ask for the input and output information interactively:

```text
==============================================
 Chemkin to OpenFOAM 8-13 Mechanism Converter
==============================================

Chemkin input directory: ./DRM19
Chemkin mechanism file name: chem.inp
Chemkin thermo file name: therm.dat
Chemkin transport file name: tran.dat
OpenFOAM output directory: ./chemkin
Use ck2yaml --permissive? [y/N]: y
Pressure for PLOG reactions in atm, empty = keep PLOG format:
Start conversion? [Y/n]:
```

After successful conversion, the output directory will contain:

```text
chemkin/
├── chem.yaml
├── thermos
├── reactions
├── elements
└── transportProperties
```

---

## Input Files

The input directory should contain Chemkin-format mechanism files, for example:

```text
DRM19/
├── chem.inp
├── therm.dat
└── tran.dat
```

The file names do not need to be fixed. The program will ask you to enter them during execution.

---

## Output Files

### `chem.yaml`

The intermediate Cantera YAML mechanism generated by `ck2yaml`.

### `thermos`

OpenFOAM species thermodynamic data file.

It contains:

- species list
- molecular weight
- JANAF / NASA polynomial coefficients
- Sutherland transport parameters
- elemental composition

### `reactions`

OpenFOAM reaction mechanism file.

It contains converted reaction blocks for supported reaction types.

### `elements`

OpenFOAM element list file.

### `transportProperties`

OpenFOAM-style transport property file containing fitted Sutherland parameters for each species.

## PLOG Reactions

For pressure-dependent Arrhenius reactions, the program provides two options.

If the pressure input is left empty, the program keeps the PLOG data in the generated OpenFOAM reaction file.

If a pressure is specified, for example:

```text
Pressure for PLOG reactions in atm, empty = keep PLOG format: 1.0
```

the program evaluates the pressure-dependent reaction rate at the specified pressure and writes it as a standard Arrhenius reaction.

---

## Notes on Temperature Range

Some Chemkin thermo files use a lower temperature limit of 300 K. If the OpenFOAM simulation starts exactly at 300 K, OpenFOAM may print warnings such as:

```text
attempt to use janafThermo out of temperature range 300 -> 3000; T = 300
```

This is often caused by floating-point round-off, where the actual temperature is slightly below 300 K even though it is printed as 300.

A practical solution is to set the OpenFOAM output lower temperature limit slightly below 300 K, for example:

```python
FOAM_TLOW = 250.0
```

or to initialize the simulation at a slightly higher temperature, such as 301 K.

---

## Limitations

This converter currently supports the most common reaction types used in combustion mechanisms:

- Arrhenius
- three-body Arrhenius
- Troe falloff
- Lindemann falloff
- pressure-dependent Arrhenius / PLOG

Other reaction types, such as Chebyshev or non-standard custom reaction models, may not be supported.

If an unsupported reaction type is detected, the program will print a warning and skip that reaction.
